# 🚀 antigravity_proj

Google Antigravity 및 AI 에이전트 협업 기반의 개발 프로젝트 저장소입니다.

---

## 📌 프로젝트 소개
`antigravity_proj`는 AI 코딩 에이전트와의 원활한 페어 프로그래밍 및 체계적인 개발 관리를 위해 구성된 프로젝트입니다.

---

## 💻 개발 환경 (Environment)
- **운영체제(OS)**: Windows (PowerShell 환경)
- **주 언어 및 런타임**: Python 3.13+
- **문자 인코딩**: `UTF-8`

---

## 📜 개발 지침 및 규칙
프로젝트의 세부 코딩 스타일, 예외 처리 원칙 및 에이전트 작업 지침은 [AGENTS.md](AGENTS.md)를 참고하시기 바랍니다.

- **표준 라이브러리 우선**: 기본 내장 모듈 위주로 개발하며 불필요한 외부 의존성을 최소화합니다.
- **클린 코드 & 가독성**: PEP 8 표준 준수 및 직관적인 네이밍/문서화를 지향합니다.
- **안전한 데이터 처리**: 파일 I/O 시 UTF-8 인코딩 명시 및 철저한 예외 처리를 적용합니다.
